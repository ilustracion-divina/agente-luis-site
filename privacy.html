Privacy Policy for Agente Luis

Last updated: October 2, 2026

Overview

Agente Luis is a private personal application used by its owner to access and manage authorized files stored in Google Drive.

Google User Data

Agente Luis accesses Google Drive data only after the user explicitly authorizes access through Google OAuth.

The application uses this access to retrieve, read, organize, and update files requested by the authorized user.

Data Sharing

Google user data accessed by Agente Luis is not sold, rented, or used for advertising. The application does not make Google user data available to unrelated third parties.

Data Storage and Security

OAuth credentials are stored as protected environment secrets and are not published in the application's public source code or website.

Revoking Access

The user may revoke Agente Luis's access to their Google account at any time through their Google Account security settings.

Contact

Questions about this privacy policy may be directed to the owner of Agente Luis through the project's GitHub account.
